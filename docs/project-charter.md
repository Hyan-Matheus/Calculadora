# Termo de Abertura do Projeto (Project Charter)

## 1. Visão Geral e Justificativa
O projeto tem como objetivo o desenvolvimento de uma **Calculadora Acadêmica** na linguagem C. A iniciativa serve como um diário de evolução e prática ao longo do meu curso de Análise e Desenvolvimento de Sistemas (Embarque Digital), permitindo aplicar novos conceitos teóricos à medida do avanço das aulas. Inicialmente com operações básicas, mas posteriormente a implementação de outras metodologias de cálculo, garantindo um código limpo, modular e bem versionado.

## 2. Objetivos do Software
* **Acompanhamento Acadêmico:** Servir como portfólio vivo de evolução em lógica de programação.
* **Evolução Gradual:** Partir de um programa focado em duas entradas fixas com as 4 operações básicas para laços de repetição avançados e funções modulares.
* **Boas Práticas de Engenharia:** Aplicar versionamento semântico, pelo GitHub Desktop por exemplo.

## 3. Escopo do Projeto

### O que está dentro do escopo (In-Scope):
* Interface de menu interativo.
* Implementação das quatro operações matemáticas básicas (adição, subtração, multiplicação e divisão).
* Correção de erros (ex: tratamento preventivo para divisão por zero).
* Implementação de laços de repetição.
* Futura expansão para cálculos básicos de figuras geométricas.
* Documentação estruturada e histórico de issues no GitHub.

### O que está fora do escopo (Out-of-Scope nesta fase):
* Desenvolvimento de interface gráfica (GUI) ou aplicações web.
* Persistência de dados em banco de dados externo ou arquivos locais complexos.
* Implementação de banco de dados.

## 4. Público-Alvo e Stakeholders
* **Desenvolvedor / Autor:** Hyan Matheus (Estudante de Análise e Desenvolvimento de Sistemas).
* **Avaliadores e Recrutadores:** Professores da instituição de ensino e profissionais de tecnologia em busca de análise de código e documentação.

## 5. Suposições e Restrições
* **Restrição Tecnológica:** Todo o código-fonte principal será desenvolvido na linguagem C.
* **Ambiente:** Execução primária em ambiente de terminal compatível com compiladores GCC.
