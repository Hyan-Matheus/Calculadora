# 🚀 Calculadora Acadêmica & Diário de Evolução

Este repositório tem o objetivo de acompanhar meu desenvolvimento acadêmico no curso de Análise e Desenvolvimento de Sistema, como aluno do programa Embarque Digital, colocando em prática meus aprendizados na construção de uma calculadora. O que a princípio pode parecer irrisório se tornará um programa eficiente na análise de minha trajetória.

## 🎯 Sobre o Projeto
Começando com as 4 operações básicas e posteriormente englobando cálculos simples de figuras geométricas.

## 🛠️ Tecnologias Utilizadas
   Linguagem de programação: C
   Conceitos aplicados: lógica de programação

## 📈 Principais objetivos
- [ 1 ]  Observar os avanços ao longo do curso.
- [ 2 ]  Encontrar as relações entre os tipos de estrtura do código e como conecta-los na prática.
- [ 3 ]  Correção de bugs e mitigar os chamados códigos mortos.
- [ 4 ]  Implementação de novas funcionalidades.
